# invoice reporting automation ♡

*turning messy invoices into clean insights.*

An Excel & VBA automation project built around **12,000 synthetic invoice records** from a fictional Polish company.

The project is designed to validate invoice data, identify discrepancies, automate regional reporting and present business insights.

---

### 01 / project goals

- ✧ validate invoice data and identify errors
- ✧ detect duplicate invoices and missing values
- ✧ generate separate reports for Polish regions
- ✧ automate repetitive reporting tasks using VBA
- ✧ create a black & pink Excel dashboard

---

### 02 / tech stack

`Excel` · `VBA` · `PivotTables` · `Data Validation`

---

### 03 / dataset

**12,000 fictional invoices** covering Polish regions, suppliers, departments and cost centers.

The dataset contains deliberately introduced errors to test validation logic.

All data is synthetic. No confidential company information is used.
